### D01 — 完整合并与发布

应用版本统一为 `0.12.2`，Python Hatch 从 `package.json` 读取，不新增独立版本常量。
保留上游两版变更日志及已有分支历史。`@codemirror/merge`、Mermaid 通过 npm 维护锁文件，
Python 标准／slim 依赖保持已有边界。可选 Valkey 使用者需 `valkey-glide-sync>=2.5.2`；
不向所有安装强制增加 Valkey 依赖。

实际标准容器编译触发默认约 4 GiB Node 堆溢出，因此前端构建阶段新增可覆盖的
`NODE_OPTIONS=--max-old-space-size=6144` 构建参数；最终 Python 镜像不继承它。

保留现有发布版本比较、排队、发布说明截断及固定提交链接。上游截断需求已由现有脚本覆盖，
不恢复旧发布目标。向 `main` 推送版本变更会触发发布；本次仅授权本地整合。

### D02 — 分发、回放、压缩与引用

仅服务器注册的内置 `call_tool` 可将封装调用解析为实际工具。先保存 `provider_function`，
实际目标用于权限、原始 Gemini 参数校验、审批、执行和结果类型；供应商回放恢复原封装。
保存每次调用的校验模式，审批恢复和续轮切换模型不能绕过。外部同名工具没有内置信任。
无效封装结果也进入 stateful Responses 后续请求，避免错误消失或重复执行。

保留跨轮调用 ID、流式去重、确定性拆分和重试不执行工具的契约。普通执行与审批恢复使用统一
引用入口，新来源只随新结果追加；保存的引用文本与历史输入前缀不重建。外部知识来源保留标题和链接。

Legacy 采用 v0.12.2 轮间检查点及单轮 usage；无效标记不裁剪历史，原始消息和结果保持完整。
off／V2 不运行 Legacy 截断。V2 继续计算最终完整请求，包括封装调用、工具定义、媒体、引用和 JSON，
只为服务器确认的新结果分配预算，已采用历史版本仍为固定输入。

### D03 — 所有者通话与旧转写

用户明确采用上游限制：普通及 Realtime 通话仅聊天所有者可发起，非所有者管理员也不能绕过。
切换到他人聊天时关闭现有通话，后端通话入口及新转写插入同步检查所有权。临时／新聊天沿用
原有语义；普通语音听写不扩大限制。

保留模型权限、持续身份与访问复查，Redis 撤权服务失败返回可重试拒绝。
旧转写不删除或重写，公开作者／浏览器来源标记及作者私有 speech/request 元数据过滤继续生效。
旧消息的作者元数据更新、回复审批、停止和共享 V2 仍按原合同执行。
接入 Azure Realtime、普通通话头像、唤醒锁及音频资源释放修复；代码与模拟测试不证明真实服务验收。

### D04 — 概览、搜索、分页与归档

用户明确采用上游概览：启用技能工具且正文超过 20000 字符时首次给出 5000 字符；未启用时
仍最多注入 100000 字符。概览、`grep_skill_files` 和 `read_skill_file` 共用固定版本及准备后的
运行时正文，中文字符和 `{baseDir}` 替换的偏移一致。准备后的正文仅存请求缓存，不写入聊天。
终端读取携带指纹，变更后拒绝沿用旧偏移。历史 pin 只选择快照，不授予当前请求访问权。

搜索属于可信内置精确结果，按完整匹配条目／位置缩减，保留绝对偏移及遗漏计数，不做语义摘要。
连最小有效条目也无法容纳时返回可操作错误。同名外部工具继续普通处理。
自动发现仍要求工作区管理员白名单或终端连接 opt-in，再检查资源 ACL；显式选择和模型预设不被发现开关禁用。

`.skill` 为 ZIP 兼容包，导出支持 `format=skill` 和历史版本；归档网络、路径、链接、大小及数量
检查继续覆盖整个输入。原生与 OpenClaw 均以 `data.files` 为唯一可编辑树，保留未知 frontmatter、
source/config/env 和原始字节。`expected_version_id`、旧描述 URL 响应及 `response_format=packages`
保持兼容；旧不可变快照不重写，终端不可用时按既有策略软失败。

### D05 — 比较编辑与控件

合入修订比较、Keep both、多模型消息配对、草稿工具选择及评分保留。
比较应用前验证草稿与所选版本仍未变化；技能编辑仍验证期望版本。
保留模型授权、Gemini 显式配置、控件优先级、有效值显示、增量设置保存、思考状态及流式错误恢复。

### D06 — 终端及无文本冲突边界

文件读写、HTML 源码、Notebook、批量删除、ZIP 和比较读取携带正确聊天上下文。
签名文件链接仍绑定原用户／连接／上下文；HTML/SVG 隔离和同源端口预览禁用继续有效。

Apps 权限是本次另行确认的设计选择：只读成员可保留私有交互；公开回复和任何已存消息更新
在 App 返回后复查写权限。频道功能权限及私有群组成员规则同样适用，管理员不因身份获得
私有群组成员资格。此规则避免只读交互变成公开频道写入入口。

无文本冲突区域也检查了 SCIM 管理员保护、频道消息元数据、向量集合别名授权、Redis Sentinel
凭据及 Socket.IO、自动化完成状态、记忆重建并发、MinerU 和 Milvus TLS。
审计模型 ID 在别名转换前保留；`{{MODEL_ID}}` 是自定义请求头替换，不是新增通用提示词变量。

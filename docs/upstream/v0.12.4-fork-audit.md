## 复核方式

使用 `git diff --numstat --no-renames <official SHA>` 获取完整树净差异，另列
`git ls-files --others --exclude-standard` 和 `git diff HEAD`；对所有路径计算文件摘要。
用 `git log <official SHA>..HEAD` 读取全部可达提交，核对 merge parents 和浅边界。
不要以远端 compare 最多返回的文件列表代替完整树统计。本快照明确区分已验证代码提交、
最终文档工作区与审计自身增量；后续修改应另算新快照。历史 v0.12.2 文件保持原样。

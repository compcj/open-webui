## 复核方法

用 `git diff --raw --numstat --no-renames <official>` 核对已跟踪树差异，
再用 `git ls-files --others --exclude-standard` 加入非忽略未跟踪路径。生成时关闭索引刷新。
清单 SHA-256 的输入是按路径排序的 JSON 数组，每个条目含相对路径和当前原始文件字节的 SHA-256。
工作区换行和文件内容会影响摘要。两个审计输出单列且不纳入该数组。

用 `git log --topo-order <official>..<code-head>`、`git merge-base`、提交父节点及浅边界核对历史。
远端比较用于补全提交，逐文件差异从本地固定官方树和当前工作区计算。
此工作区的生成脚本位于 `.agent-work/v0133/generate-fork-audit.py`，使用已安装的 Prettier。
归档后重跑时传入 `--code-head <merge-sha>`，保持同一代码截止点。

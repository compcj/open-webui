# v0.13.3 Gemini cache replay follow-up

## Scope and baseline

Recorded on 2026-11-12 against fork base `843a4eabf6a9a69ad272190d0af61443272d3425`.
This follow-up fixes model system prompt preparation and Gemini signatures through Chat Completions.
It preserves the [citation-prefix decision](v0.11.4-tool-citation-cache-followup.md) and keeps
[native signed reasoning](v0.12.2-native-connections-followup.md) independent. It does not alter cache
creation, provider routing or cache lifetime controls.

## Cause and implementation

The chat dispatcher copied input before the OpenAI router injected the model system prompt. Tool
middleware then continued from the earlier canonical input while bypassing reinjection, losing the
model's prompt. `main.py` now calls `prepare_chat_system_prompt` before initial dispatch and shares
that prepared input with response middleware. Canonical request metadata retains precedence;
browser-direct model-ID collisions do not trigger server model lookup. Standalone calls, internal
tasks and existing Ollama/Pipe dispatch keep their semantics.

Streamed calls and stored output projections previously dropped Gemini's
`extra_content.google.thought_signature`. `utils/gemini_signatures.py`, stream assembly and output
replay now preserve that carrier at the original call/message level, including late deltas, batch
wrappers, saved approval resumes and reload. Signature handling does not replace `reasoning_details`.
Message-level carriers participate in V2 counting and fingerprints. Model-switch projections remove
old carriers without editing stored originals.

Signed text is restored from the current stream's original content and keeps independent Continue
boundaries. Review identified that legacy code continuations retain earlier output in the same list:
coalescing is therefore limited to current-stream items, keeping earlier messages and completed code
in order. The regression first reproduced five executions, then verified one execution with the
earlier text retained after the fix. Already completed effects are never retried to recover a signature.

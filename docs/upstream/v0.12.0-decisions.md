## 本次决策

### D01 — 完整合并与发布边界

完整合入官方目标，保留真实 Git 祖先，采用上游知识文件浏览、资源版本历史、群组嵌套和默认模型、
多人续写、Realtime、MFA、持久化会话撤销、Tool Search 与独立插件开关。
保留分叉发布流程，不恢复 PyPI 和 Docker Hub 发布步骤。Tool Search、强制 MFA、Realtime 通话
按上游默认配置，升级不主动开启。标准镜像仍为主要验收目标；slim 接入上游 S3，其他精简边界不扩大。
这保留 v0.11.4 D01，替代 D10 中 slim 仅本地文件存储的限制；代码接入不代表真实服务验收。

### D02 — 压缩分流与固定引用

全局 off 回放原始历史，legacy 使用 v0.12 轮间算法，V2 独立接管最终发送和超窗重试；
同一请求不重复运行两套压缩。旧开关仅迁移为 off/legacy，不自动启用 V2。
原始聊天、legacy `contextSummary` 和 V2 检查点各自保留。引用规则在首发前安装，
`citation_context` / `citation_sources` 固定保存并回放，后续来源仅随对应新工具结果追加。
保留 v0.11.4 D05 与引用缓存后续决策；旧“保持原 legacy 算法”约束由本项替代。

采用上游并发审批、暂停恢复、附件按消息配对、MCP 结构化结果处理，并对原生续调按 call ID 去重。
冲突和超窗重试只重算请求，不重新执行工具；已选用历史版本不因新任务或设置变化而重写。
V2 保留历史优先、公平分配、发送前原子选用、摘要模型独立预算、原文查询和回复归属通知。
新拼接 JSON 工具调用使用确定性子 ID 并保留原始调用来源；历史上已被随机改名且未保留来源的旧调用，
无法反推出丢失的供应商 ID，不改写这些不可变历史以猜测去重关系。

Tool Search 的完整实际定义、清单和结果都进入预算。服务器注册的 `search_tools` 结果按完整条目处理，
`view_skill` / `read_skill_file` 按精确页缩小，不走语义摘要。无法容纳一个必要条目时返回错误，
而不发送不完整 schema；同名外部工具不能自行声明这些可信处理类型。

### D03 — 共享 V2 状态与个人上下文

同一聊天、模型和有效分支共用检查点与工具选用，不添加参与者维度。共用摘要仅取已保存的共享分支历史，
个人系统指令、变量、终端上下文仍属于当前请求并计入发送预算。数据库来源标记 `saved_history_v1`
只由服务端写入；旧记录缺少证明时保留数据库原值，共享请求回放原文。
这让协作者使用相同历史版本，避免把未知来源的私人上下文误当成共享摘要。

准备提交继续验证来源和并发获胜者；切换为共享后的旧已选用摘要回退原文，不改变原有选用身份。
只读状态和原文读取使用聊天读取权限与分支校验。克隆/导入清除检查点、工具选用和压缩统计身份，
保留原始消息及引用；旧聊天游标仍绑定旧聊天，不能在克隆中复用。只克隆分享限定为分享快照。

每次发送复查当前参与者的模型、工具和连接权限；聊天所有者的私人配置、变量和凭证不传给其他参与者。
审批/停止仅属于回复作者，手动 `/compact` 仅所有者可用。撤销共享或群组权限后，后续读取和实时更新拒绝。
共享状态查询不代表某个参与者尚未提交的私人上下文，最终发送仍重新核算完整请求。
所有用户可见聊天响应（含导出、列表和修改接口）按消息作者过滤私人元数据；克隆/分叉在持久化前过滤。
服务端审批读取仍保留作者的请求快照。读/写授权沿用上游的独立 grant，续写成员需要相应的读和写权限。

### D04 — 技能文件统一与版本兼容

`data.files` 是唯一可编辑文件树，保留文本/base64 表示。旧 OpenClaw `meta.openclaw.files`、
frontmatter、source、config/env 经适配器无损转换，未知非秘密元数据保留，运行条件、终端文件同步、
`{baseDir}` 和显式依赖安装继续工作。文件树编辑后不维护第二份可变旧附件或正文。
旧正文按原有序列化语义补齐 `SKILL.md`，已有有效新版文件优先；不同内容的路径碰撞属于错误。
本地 Markdown、ZIP 和目录导入识别带 frontmatter 的兼容包并保留运行来源标记，原生 JSON 不因文件树
存在而自动变为 OpenClaw。同步缓存按实际终端用户、连接与上下文隔离；根正文的运行时替换仅缓存在当前
请求中，`view_skill` 和后续 `read_skill_file` 使用同一份正文计算分页偏移，包括 V2 缩短后的首个页面。

迁移先验证数据，再写入当前兼容版本；失败报告技能 ID/路径并停止，不截断或悄悄跳过文件。
旧不可变快照保持不变；读取旧快照经过兼容投影，恢复时生成有归属的兼容版本。
新文件编辑使用 `expected_version_id`：过期版本冲突，旧附件编辑缺少版本时明确要求刷新客户端。
旧模型控件/技能历史快照均不作为迁移时可随意改写的数据。

`POST /api/v1/skills/load/url` 保留默认下载描述对象，`response_format=packages` 返回解析技能列表；
两种响应共用受限下载器、重定向校验、归档/大小限制及解析器。保留 GitHub repo/tree、skills.sh、
ClawHub、直接链接和多技能选择；采用上游内网拒绝规则。管理员或有 `skills_import` 权限者可导入。

v0.11.4 D02/D03/D04 保留：自动发现必须分别满足管理员白名单/连接 opt-in 和资源 ACL；
手动技能/模型预设不因发现关闭而失效，终端 AGENTS.md 独立软失败。
本项替代旧 `openclaw.files` 为附件持久化来源的约束，保留其导入、导出及运行兼容性。

### D05 — 模型控件、默认与重置

普通服务端模型统一采用上游控件；直连、pipe 等不支持场景保留原入口，Responses 继续转换
`reasoning.effort`。旧标准/自定义档位映射为合法选项 ID；模型默认、用户记忆和聊天选择均可迁移。
已有新格式配置优先，旧字段仅作为兼容输入，不形成双份可变配置。
显式选项整体替代该控件的默认选项，即使其参数是空对象；不同控件仍可组合。控件展开与实际供应商参数
转换都允许 JSON 对象替换 null/标量/数组，不让旧默认值造成异常。

有效值依次为：会话显式控件 → 用户记忆控件 → 会话高级参数 → 个人高级参数 → 控件/模型默认 → 全局默认。
默认/重置消费并清除旧记忆，不能在刷新时恢复已清除选择；界面显示实际有效值。
保留增量设置保存队列、账号隔离、中文输入法、窄屏布局及知识/记忆/笔记独立开关。
此项部分替代 v0.11.4 D06 及“推理强度独立入口”规则，其余交互和保存契约保留。

### D06 — 安全与其他保留能力

保留 v0.11.4 D07/D08/D09：个人直连入口默认、终端文件用户/上下文签名绑定、同源端口预览禁用，
Redis 撤销检查不可用时 HTTP 503 / 终端与 Realtime WS 1013，且不删除有效 Cookie。
持久化撤销和实时连接复查采用上游机制，实时广播也检查最新聊天/群组权限。

Tavily 支持 `ultra-fast`、`fast`、`basic`、`advanced`，仍默认 basic；严格校验，省略/null 更新
保留旧设置，搜索和提取深度独立。Search1API、命名图像引擎、生成/编辑配对与禁用、图像上下文去重、
ComfyUI 错误详情和 Tika JSON 协商继续保留。管理员保存的终端连接仍是自动发现授权的唯一来源。

## Decisions and rationale

- Select Chat Completions, Responses, Gemini or Anthropic explicitly. URL/model inference is ambiguous
  for compatible gateways. Keep `OPENAI_API_*` configuration and legacy values to avoid migration
  and accidental changes to existing connections. Native protocols belong to admin server Connections.
- Preserve custom gateways and existing auth/header/identity behavior. Native API-key headers are
  protocol-specific; explicit controls keep precedence. Reject native+Azure instead of guessing.
- Normalize native text, images, tools, approvals, usage and streams into existing chat flows. Keep
  exact signed blocks/parts in an optional, validated `reasoning_details` envelope tied to protocol,
  connection, model and original content. Invalid required signatures fail rather than silently
  changing history or repeating tool execution.
- Keep thinking configuration explicit through existing model controls/native custom parameters.
  Apply Anthropic's absent-only 4096 output default before budgeting. Administrator context windows
  remain authoritative; model names do not establish version-specific limits.
- Include native replay and framing in final budgeting before adopting tool-result selections.
  Preserve frozen citation prefixes and off/legacy/V2 contracts. Native Gemini's default JSON Schema
  transport and manual restricted-schema projection remain separate choices.
- Keep scope to message transports and model discovery. This change adds no Vertex/Bedrock,
  personal native direct, native search/cache-management, audio, embedding or image-generation APIs.
  Unsupported endpoints return explicit errors.

## Implementation verification (2026-10-16)

Verification used Node 22.23.3 and Python 3.12.15 with isolated backend data/static/database paths.
The full backend run passed 1760 tests and skipped six optional PostgreSQL cases; the final focused
regression after review fixes passed 346 tests. Review fixes cover late Gemini response IDs, unsupported
management endpoints, blocked/thinking-only nonstream completion, and signed response boundaries
across Continue. Approval/reload tests assert completed tools are not executed twice.

Frontend verification passed 50 connection tests. The full frontend run passed 481 tests across
59 files; one existing suite could not load the declared but locally missing `@codemirror/merge`
dependency. `npm run check` remains unsuccessful (5001 errors and 184 warnings); a scoped baseline
comparison found no new diagnostics in the changed frontend files. Translation extraction is run
twice to verify stable catalogs. Markdown links/heading anchors, formatting and diff checks are
checked separately from runtime tests.

No official Gemini/Anthropic or compatible-gateway credentials were supplied, so real-provider
acceptance remains unperformed. No browser was available through the enabled UI tools; keyboard,
narrow-screen and live connection-form acceptance remain manual checks. No production build,
publication or deployment is claimed by these results.

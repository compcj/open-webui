## 已发现并修复的合并问题

- 原生流 reducer 搬迁、异步技能读取、Config 批量读取、索引函数拆分和新 usage 参数使旧隔离测试夹具失配；保留原行为断言，调整到当前真实函数边界。
- Legacy 续接中失去来源的局部变量已改用当前用户消息正文。
- 共享导入／复制重新归属消息前剥离他人私有 `meta`，避免把他人私有上下文改标为自己的资料。
- V2 工具和代码续接仍引用被上游重构删掉的 `model_id`；whole-stream 回归先重现失败，再改为当前请求模型，验证登记后才继续发送。
- 已保存互动恢复在每次投递及接受结果前重查凭据、write ACL 和回复作者；跨 worker 只向 Socket 所属 worker 请求鉴权，server-only nonce/scope 配对，不把共享路由池当凭据证明。
- 新加密 Relay 原先绕过 fork 的本地投递鉴权。现由接收 worker 重查凭据、频道权限和功能开关；只有不携带内容的结束通知允许在频道授权撤销后清理 UI。Redis／鉴权异常不转为广播。

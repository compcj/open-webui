## 上游已覆盖和需要纠正的旧描述

- **Tavily**：官方已经有 `ultra-fast`/`fast`/`basic`/`advanced` 选择及请求传递；本分支差异在校验、默认显示和保留已有配置，不能把四档选择整体称为新增。
- **模型与技能基础能力**：模型控件、资源历史、知识文件浏览、技能文件树/概览/搜索/`.skill` 来自上游；分支保留旧值迁移、OpenClaw、运行时准备、发现授权及精确结果预算。旧独立推理编辑组件和未调用的兼容 helper 不能作为当前 UI 功能的证据。
- **通话、比较和文件操作**：所有者通话、Azure Realtime、修订比较/Keep both、多模型配对、Notebook/批量删除/ZIP 来自上游；本分支的作者隐私、实时授权、草稿守卫、终端隔离、迟到结果清理和并发请求隔离单列。

## 近期回复生命周期修复

这三项发生在原始 v0.12.2 合并验收之后，不能使用原验收数字证明其运行效果。

1. **`d9a49acba` — 停止必须等执行者确认。** Pub/Sub 只是快速通知，停止意图与租约分开保存；worker 轮询补偿漏消息，只有执行者清理才确认完成。超时保留任务供重试，重复停止不再次中断清理。前端不提前清空状态、出队或继续 bridge 请求，导航后不修改新回复。停止是结束任务，不是回滚已发生的外部写入。
2. **`d8929995d` — 保存中断前结果，按协议完成。** 传输异常先保存缓冲文字和前轮结果，将运行中输出标为 incomplete，再传播错误；本轮不完整工具/代码不执行。SSE `[DONE]` 独立于 HTTP EOF，完成后不继续读迟到错误或等待连接关闭；普通正文里的同名字符串不触发完成。
3. **`c21cfb72b` — 比较请求逐回复隔离。** 深复制 form data 和 metadata，为每个并发模型创建独立 mutable request state，阻止 V2 分支、工具选用、重试和缓存串扰；同模型重复比较也隔离。已读 body 的不可变字节保留给插件，各回复自行解析 JSON。

用户说明见[聊天访问和停止](../chat-access-controls.md#stopping-and-interrupted-responses)，
后续合并必须同时检查[后端规则](../../backend/AGENTS.md)和
[前后端回归命令](../DEVELOPMENT.md#chat-lifecycle-and-request-isolation-verification)。

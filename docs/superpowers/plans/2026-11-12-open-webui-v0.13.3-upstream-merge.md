## 阶段 A：上游合并与核心适配

- 上下文：请求内隐藏项与持久 output 分离，不能由客户端伪造可信来源；全部计入最终预算，但不获新结果预算身份。保留冻结引用、原生签名、off/legacy/V2、选用版本和共享边界。Legacy 接入缓存优化，V2 摘要保留独立预算。

## 阶段 B：Tether 与 Agents

- 环境/API 字段 `ENABLE_TETHER`、存储 `tether.enable`，默认 false。现有管理员 Connections API、Integrations UI；省略保留。
- 覆盖握手、发现、HTTP/WS、自动化；关闭禁止新操作、关闭通道，运行任务按确认停止规则。只信任服务端认证设备。
- 不增加管理员终端技能发现或知识导入资格；保留用户绑定、撤权、Redis 故障可重试拒绝。
- Agents 仅保存聊天、单 Agent、禁止重新生成/继续旧回复/原地分支；自有上下文，不套 WebUI V2。
- Agent state 绑定作者/聊天/终端/cwd；分享/复制/侧聊不继承续跑身份。自动化执行前重查终端和 Agent。
- 远端停止需完成确认；不能吞关闭失败。超时、断线、丢响应保留不确定状态和停止意图，不以 404、租约或本地协程退出推断完成。

## 阶段 C：独立来源预览

- `TERMINAL_PREVIEW_BASE_URL` / `terminal.preview.base_url` 默认空；独立主机名，生产 HTTPS，明确本地例外。
- 后端独立 Host 仅含预览 HTTP/WS；不能访问主站 API/登录/Socket.IO；主站继续拒绝同源终端 HTML/端口代理。
- `POST /api/v1/terminals/{server_id}/preview-tickets` 只接受已授权浏览器会话或端口，绑定原聊天/临时身份，返回 `{url, expires_at}`。
- 随机不透明能力票据绑定用户/登录会话/终端/目标/上下文；5 分钟 TTL，活跃页每分钟重新授权。票据/凭据只在服务端，不进布局。
- Redis 共享状态且故障可重试拒绝；无 Redis 仅单 worker 内存。撤权/退出/关闭 scope/禁用使票据失效并关流。
- 资源/导航/表单/SSE/WS/HMR；严格响应/iframe sandbox，无 allow-same-origin/顶层跳转/站点存储；主站拒绝预览来源凭证访问。
- 日志票据脱敏、no-store/no-referrer、精确 postMessage。可选 Compose/代理示例，不更改现有部署。

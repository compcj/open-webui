# Tether 与原生 Agents

Tether 将用户设备的 Open Terminal 连接到 WebUI。管理员在 **设置 → Integrations** 开启
Tether，或为首次配置设置 `ENABLE_TETHER=true`；持久化键为 `tether.enable`，默认 `false`。
已保存管理员配置优先；旧客户端更新其他 Connections 字段时不会清除此值。

## 开关与授权

| Tether | Direct Integrations | 可用连接                                     |
| ------ | ------------------- | -------------------------------------------- |
| 关闭   | 关闭                | 已授权管理员服务器连接                       |
| 开启   | 关闭                | 管理员服务器连接与当前用户绑定的 Tether 设备 |
| 关闭   | 开启                | 管理员服务器连接与允许的手工个人工具/终端    |
| 开启   | 开启                | 上述连接，分别执行自己的权限检查             |

模型 Direct Connections 和 Direct API Chat 仍独立控制。插件总开关、终端功能及模型权限仍适用。
`ENABLE_WEBSOCKET_SUPPORT` 也必须开启；关闭全局 WebSocket 时不提供 Tether 发现或新操作。
Tether 设备身份来自认证后的服务端记录，客户端传入的设备 ID 不授予其他用户访问权。
关闭开关后禁止新的握手、发现、调用和自动化，关闭已有通道；不会把尚未确认结束的远端任务标为完成。
重新开启后设备需重新连接。会话撤销立即影响后续授权，配置 Redis 后撤权检查失败返回可重试错误。

Tether 不能继承管理员终端连接的技能自动发现 opt-in，也不能用作知识库终端直接导入来源。
手动技能、模型预设及其他工具继续遵守各自权限。详见[知识写入](knowledge-write-tools.md)。

## Agent 聊天

选择终端提供的 Agent 模型并使用已保存聊天；每次只运行一个 Agent。上下文由 Agent 管理，
WebUI 的 off/legacy/V2 压缩不介入其内部会话。Agent 聊天不支持重新生成、继续旧回复或原地创建分支。
终端、Agent 或目录不可用时，保留原模型身份并提示离线；等待恢复或手动选择普通模型。
自动化在开始前重新检查终端和 Agent 的可用性。

Agent 会话绑定回复作者、聊天、终端与工作目录。分享、复制、导出和侧聊只传递允许的可见原文，
不复制可续跑的 Agent 会话或执行身份。切换目录/终端不会把旧会话附到新目标。
续跑签名同时绑定实际终端地址；连接 ID 相同但地址变化也不能沿用旧执行身份。

## 停止与故障恢复

开始远端操作之前保存执行记录。停止后先保留停止意图，再要求 Open Terminal 确认执行已结束；
确认成功并保存已接受的原文后，原子地完成回复并解除下一轮阻塞。重复停止不能中断清理过程。
审批与停止属于回复作者，管理员不能代替其他作者绕过此边界。

服务端按序持久保存收到的 Agent 原始帧后才发送确认，再保存可见输出。私有原始帧日志不进入
客户端历史、分享、复制、导出或续跑输入。每条回复默认最多保留 64 MiB、65536 个事件，可用
正整数环境变量 `AGENT_NATIVE_OUTPUT_MAX_BYTES` 和 `AGENT_NATIVE_OUTPUT_MAX_EVENTS` 调整。
这些是原文保留容量，独立于工具轮次和子代理执行限制。
触及容量的首个原始帧先写入有界应急保留区而不确认，随后停止接收并进入不完整停止流程。
恢复 worker 只按已保存游标重新附着读取原会话，不重发 Agent 输入；私有日志在 SQL 投影层排除，
普通聊天列表和读取不会反复加载整份原始帧。

按用户确认的强制停止策略，当前终端协议允许强制删除远端会话并终止进程，可能丢失尚未传回的
尾部输出；界面须明确标记不完整。已持久保存并确认的帧不丢弃、不重跑，存活 worker 手中的待保存
帧先保留。进程崩溃发生在收到字节但尚未持久提交之间时，未确认的尾部也可能缺失，不能宣称无损。
这不改变终止确认要求：远端关闭无明确成功响应时，原文部分保存也不能解除阻塞。

如果断线、关闭超时、丢失启动/关闭响应或返回 404，界面保持“未确认”状态，后续回复被阻止。
后台按原身份重试关闭；用户再次停止也只重试关闭，不能重发输入或重启任务。服务重启后保留的
执行记录继续阻止错误推进。若启动已发生但响应丢失，WebUI 没有可靠远端 session ID，不能猜测完成；
需恢复终端并由运维核实远端进程状态，再采用有审计依据的恢复流程，不能删除记录后自动重跑。

Redis Pub/Sub、TTL、过期租约、缺失任务索引及本地协程退出均不是执行完成证明。升级前排空任务，
避免旧 worker 与新 worker 混用执行记录。回滚恢复升级前数据库、上传、配置与镜像整套备份。

## 浏览器与文件

Proxy 网页/端口通过[独立来源预览](terminal-preview.md)，默认没有部署入口。Chrome 模式提供完整浏览器
能力，控制通道使用服务器保存的短期授权并持续检查当前用户/聊天/终端访问。普通文件下载和隔离图片
交付沿用[终端文件指南](TERMINAL_FILES.md)，不会恢复主站同源网页代理。
